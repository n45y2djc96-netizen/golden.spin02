# Golden Spin

Telegram Mini App с играми на виртуальных токенах.

Игры:

- 🎰 Слоты
- 🎲 Рулетка
- 🎡 Колесо
- 🧰 Сундуки
- 🔨 Разбить блок

В текущей версии:

- нет вывода денег;
- нет обмена токенов на деньги;
- используются только виртуальные токены;
- баланс хранится локально в браузере.

## Запуск

Откройте index.html через HTTPS-хостинг.

Для Telegram Mini App используйте HTTPS URL.
